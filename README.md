# Élan Fitness

## Présentation du projet

Élan Fitness est un site web pour une salle de sport située à Casablanca. Le projet consiste à transformer un site monopage en un site multipage afin d'améliorer la navigation et l'expérience utilisateur.

## Technologies utilisées

* HTML5
* CSS3
* Responsive Design
* Git et GitHub
* GitHub Pages

## Pages du site

* Accueil
* Programmes
* À propos
* Contactez-nous

## Installation locale

1. Cloner le repository :

   `git clone https://github.com/AyoubHs0/elan-fitness.git`

2. Ouvrir le dossier du projet.

3. Ouvrir `index.html` dans un navigateur web.

## Objectif pédagogique

Mettre en pratique les compétences en HTML5, CSS3, Responsive Design, gestion de versions avec Git et publication avec GitHub Pages.
